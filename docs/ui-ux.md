# UI & UX Specification

**Version:** 0.1  
**Status:** Initial concept

## 1. UX principle

Easy to learn, fun to explore. The interface should reveal complexity only when the player needs it.

## 2. General layout

- Isometric world remains the focus.
- Compact top-level HUD for credits and key progression.
- Context panel appears when selecting an item, machine, employee, or Scrappy.
- Small task / objective area.
- Minimal nested menus.

## 3. Context actions

For an item:
- Pick up.
- Sell.
- Inspect.
- Process, if compatible.
- Keep / mark, where appropriate.

For a machine:
- Status.
- Input / output.
- Upgrade.
- Configure a small number of simple options.

For Scrappy:
- Current parts.
- Available parts.
- Abilities.
- Appearance.

For an employee:
- Assigned task.
- Efficiency.
- Cost.
- Reassign / dismiss.

## 4. Feedback

Every action should clearly communicate:
- What happened.
- What changed.
- What it cost or earned.
- What can be done next.

## 5. Tutorials

Use contextual guidance and Scrappy's dialogue. Introduce one system at a time. All explanations should be short and skippable where possible.

## 6. Accessibility and comfort

- Adjustable UI scale.
- Readable typography.
- Key remapping.
- Volume controls.
- Camera sensitivity and zoom options.
- Avoid color-only status communication.
