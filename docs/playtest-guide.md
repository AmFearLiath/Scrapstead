# Scrapstead — Playtest-Leitfaden (Vertical Slice)

**Stand:** 26.11.2026 · für 3–5 Personen nach MVP-Plan 11.3 · Dauer: 45–60 Minuten pro Person

## Vorbereitung
- Spiel starten, „Neues Spiel“. Nichts erklären außer: „Du hast einen Schrottplatz geerbt. Spiel einfach.“
- Laut denken lassen. Notieren, nicht helfen. Eingreifen nur, wenn jemand länger als 3 Minuten feststeckt.

## Beobachten (ankreuzen, Zeit notieren)
| # | Frage | Beobachtung |
|---|---|---|
| 1 | Wird der erste Gegenstand ohne Hilfe aufgehoben? Nach wie vielen Sekunden? | |
| 2 | Wird der Unterschied zwischen „aufheben“ und „braucht Werkzeug“ verstanden (Träger, vernagelte Kisten)? | |
| 3 | Fühlt sich der erste Verkauf wie ein Erfolg an? | |
| 4 | Wird „Walts Liste“ im Pausenmenü gefunden? Hilft sie? | |
| 5 | Wird Scrappys Kopf gefunden? Wie lange dauert die Suche nach dem Kernteil? | |
| 6 | Ist Scrappys Aufwachen ein besonderer Moment? Wird gelacht? | |
| 7 | Wird Juri eingestellt? Wird die Lohnabrechnung verstanden? | |
| 8 | Fühlt sich das Einstellen wie eine Entscheidung an oder wie eine Selbstverständlichkeit? | |
| 9 | Wird der Magnetsammler gekauft? Wird die volle Kiste bemerkt? | |
| 10 | Wo entsteht Leerlauf oder Langeweile? | |
| 11 | Was will die Person nach dem Test als Nächstes tun? | |

## Danach fragen
1. Was war das Lustigste?
2. Was war verwirrend?
3. Welche Figur ist dir im Gedächtnis geblieben?
4. Würdest du weiterspielen? Warum (nicht)?

## Zur Taktung prüfen
- Anlieferungen alle 150 s, Juris Tempo (2,4 m/s), Magnetsammler 20 s / 12 s, Kowalski alle 4 min.
- Alle Werte stehen in `data/` und lassen sich ohne Codeänderung anpassen.
